# Nivlet 使用指南

[返回首页](../README.zh-CN.md) · [English](USAGE.en.md)

## 使用说明

### 剪贴板

在“设置 → 剪贴板”启用并保存，再复制新内容。点击菜单栏剪贴板图标查看历史：图片在上、文字在下；图片有缩略图及悬停预览，文字前显示 T 方框。设置页历史仍按时间混排。

| 操作 | 方法 |
| --- | --- |
| 复制历史 | 点击菜单中的条目，再到目标应用粘贴 |
| 直接粘贴 | 按住 Option 点击条目，粘贴到打开菜单前的应用；需要辅助功能权限 |
| 搜索 | 菜单“搜索历史…”或设置页历史搜索框；支持文字，不支持图片 OCR |
| 放大图片 | 设置页图片卡片上的“放大预览” |
| 暂停 | 菜单“暂停记录”；恢复后只记录新复制的内容 |
| 清空 | 菜单或设置页“清空历史…”；确认后删除历史和缓存，**同时清空系统当前剪贴板，无法撤销** |

文本默认最多 50 条，可选 10–100 条；保留时间默认 30 分钟，可选 30 分钟、1/2/4/8/12/24 小时或永久。永久仍受数量上限限制。图片最多 10 张，每张约 10 MiB；文件复制不记录，图片粘贴需目标应用支持。

默认退出后不保留历史。“跨重启保留历史”需单独启用，缓存为本地明文。重复内容会移到最新位置，不补录启用前或暂停期间的内容。复制敏感内容前建议暂停；应用排除和过滤不能识别所有敏感信息。

### 窗口管理与应用启动

在对应设置页启用功能并配置组合键，然后保存。支持字母、数字、方向键、Return、`=` 和 `-`，字母统一大写显示；Backspace 或 Delete 清空按键。默认不预设快捷键。

窗口管理提供半屏、四角、居中、三分区、九宫格、宽高每次增减 40 点及相邻屏幕移动。恢复操作回到本次运行首次调整前的位置。全屏窗口不支持，应用最小尺寸可能限制小格布局；没有相邻屏幕时不会循环移动。

应用启动规则会启动应用或切换到前台。重复添加同一应用会提示并定位已有条目；输入法及浏览器来源规则也会检查重复应用。Nivlet 内快捷键冲突会阻止保存，但无法检测全部第三方快捷键占用。

### 浏览器分流

1. 在“设置 → 浏览器”选择“未匹配时使用”的浏览器，添加域名或来源应用规则。
2. 启用并保存，用“检查匹配”和“按规则打开”验证；“模拟来源”可检查应用规则。
3. 点击“设为默认浏览器…”并完成系统确认，再点“重新检测”。若未出现确认，使用“打开默认浏览器设置…”选择 Nivlet；取消接管时改回原浏览器。

匹配顺序为 **域名 → 来源应用 → 默认目标**。域名按列表从上到下匹配，支持子域名选项及 ↑ / ↓ 排序。支持已安装的 Safari、Chrome、Firefox、Edge 和 Brave，仅处理 HTTP/HTTPS。部分应用不提供可识别的来源，此时按域名或默认目标处理。

### 系统信息与输入法

在“系统信息”选择需要显示的网速、CPU、内存、磁盘、IPv4、IPv6、MAC、公历/星期及农历，保存后生效。设置页显示当前状态；隐藏网速后仍保留信息入口。地址和日期可点击复制。macOS 可能隐藏 MAC 地址，此时显示“系统已隐藏”，与辅助功能权限无关。

在“输入法”添加应用并为其选择已启用的系统输入法，启用并保存；下次切到该应用时生效，未配置的应用保持当前输入法。

### 外观、导航与配置

- 语言支持“跟随系统 / 简体中文 / English”，外观支持“跟随系统 / 浅色 / 深色”。默认跟随系统。
- 主图标可显示或隐藏，剪贴板和系统信息入口独立保留。目标排列为“网速 → 剪贴板 → N”，位置也受 macOS 保存的状态影响。
- 顶部标签可拖动排序；“通用”固定最左、“关于”固定最右。排序自动保存，其他可编辑设置统一点击右下角保存。
- “登录 Mac 时自动启动”保存后生效。可选 Command + L 睡眠默认关闭；启用会覆盖浏览器地址栏等应用的同名快捷键。
- 在“通用 → 配置备份与迁移”导出 JSON 或默认示例。导入时先核对替换范围，未包含模块保持不变，失败恢复原配置。历史、缓存、权限、登录项及系统默认浏览器不随配置导出。详见 [配置说明](CONFIGURATION.md)。


### 保存、取消与软件更新

修改过但未保存的标签会显示橙点；右下角“保存设置”和“取消修改”仅操作当前页，在未修改页保持禁用。切换页面保留草稿；应用启动和输入法规则可用左侧手柄拖动排序，保存后生效。

在“关于 → 软件更新”手动检查。发现新版本后确认下载并安装、重启；有未保存修改时先处理草稿。当前默认不后台检查或静默安装；检查和下载会联网，配置与剪贴板历史不因此上传。开发签名更新后可能需要重新开启辅助功能。较旧版本没有应用内更新时，从 GitHub 下载新版覆盖安装。
