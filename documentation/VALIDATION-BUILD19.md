# Build 19 本机验收

日期：2026-10-10。安装版为 1.0.0 / Build 19，Apple Silicon（arm64）专用。GitHub 正式附件和 appcast 仍为 Build 18；本轮没有发布更新。

## 替换与恢复

- 按用户授权替换 `/Applications/Nivlet.app`，先备份 Build 18 应用、Nivlet 独立数据目录与偏好；未修改个人 Hammerspoon。
- 回滚副本位于本机忽略目录 `build/backups/before-build19-20261010-222152/`，含 `Nivlet-build18.app`、`Nivlet-build18-previous-install.app`、`ApplicationSupport/` 和 `preferences.plist`。这些含个人数据，不进入 Git 或公开附件。
- 安装版 379 个普通文件与构建产物逐字节一致，严格 ad-hoc 签名通过；主程序及包内 101 个 Mach-O 仅含 arm64。
- 用户重新授予辅助功能后，应用实际检测为已开启。此为签名替换后的授权恢复，不代表权限可跨签名永久保留。
- 正常菜单退出后再次启动，进程启动时间已变化；8 项模块配置与升级前一致。原数据文件没有缺失，历史及图片缓存保持一致；仅运行时分析文件 `default.profraw` 发生变化。

## 仍未覆盖

- 真实睡眠与唤醒、真实登录启动（保持观察）。
- 其他 Apple Silicon Mac/macOS、多屏移动；Intel（x86_64/x86）明确不支持。
- 更新下载/安装取消、断网、实际安装签名失败、只读安装位置、Build 19 新旧版本升级链路。
- Developer ID、Apple 公证及完整跨机器 Gatekeeper 流程。

因此本轮结论为：本机现有主要功能、安装版动态加载及用户实体操作通过，未发现精简引入的功能回归；不声称所有硬件与更新异常场景均已通过。
