- 包内 101 个 Mach-O 全部为 arm64，包括 Runtime 扩展、Sparkle 嵌套组件和 `system-probe`。后续构建不再支持 Intel。
- 关于页图标为 160 × 160、30,197 bytes；品牌原图、Dock 和菜单栏图标未改。
- Release 主程序裁剪后 4,880,320 bytes；裁剪前后已定义外部符号一致、UUID 不变，外置 dSYM UUID 匹配。动态扩展不额外 strip。

- 全部 Lua 回归、应用替换/快捷键捕获/标签边界 Node 回归、Dock 策略及许可检查通过；严格 ad-hoc 签名、ZIP CRC、DMG 校验和、SHA-256 检查通过。Build 18 ZIP/DMG 的 SHA-256 仍匹配。
- 此处签名检查指 App 的 codesign 完整性，不代表 Sparkle Ed25519 更新包验证或 Apple 公证。
- Build 19 已安装并完成动态加载、图标、原生功能及用户实体操作验收，证据及仍未覆盖的异常/跨机器场景见 [Build 19 验收记录](VALIDATION-BUILD19.md)。
