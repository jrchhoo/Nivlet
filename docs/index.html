SMALL TOOLS. EVERYDAY FLOW.

一处入口，几分从容。

按需启用，用自己的方式配置。无需另外安装 Hammerspoon，也无需编写代码。

01 / CLIPBOARD

复制过的，还找得到。

文字与图片分组展示，搜索历史、缩略图与放大预览。可暂停记录、排除应用，按数量和时间保留。

T下一次灵感，不必重新寻找。⌕
02 / WINDOWS

窗口，各就各位。

29 项操作覆盖半屏、三分区、九宫格、居中、跨屏与恢复。快捷键由你决定。

03 / APP SHORTCUTS

按一下，就到。

启动应用或切到前台，短暂提示确认操作。更换应用、拖动排序，并检查重复与快捷键冲突。

⌥+S→ Safari
04 / BROWSER ROUTING

链接，去对的浏览器。

根据域名或来源应用选择浏览器。主动设为默认浏览器后生效，未匹配链接使用指定目标。

Telegram → Chrome
05 / SYSTEM & INPUT

状态与输入，也顺手。

菜单栏网速、CPU、内存和日期按需展示；切换应用时自动选择对应输入法。

06 / MAKE IT YOURS

习惯，不用重来。

JSON 配置导入导出，中英文和深浅色切换。每页保存、取消修改，未保存草稿有清晰标记。

完整安装与升级指南 ↗
  1. 下载安装

    从 GitHub 下载 DMG，将 Nivlet.app 拖入 Applications。DMG 或 ZIP 任选一个。

  2. 按需授权

    窗口管理和 Option 直接粘贴需要辅助功能权限。未公证包若被拦截，请查看安装指南，不要全局关闭 Gatekeeper。

  3. 配置并保存

    从菜单栏 N 图标进入设置，开启需要的模块，保存本页设置。浏览器分流还需将 Nivlet 设为默认浏览器。

数据，留在本机。

配置和剪贴板记录保存在 Mac 本地。开启跨重启历史会使用本地明文缓存；复制敏感内容前，可暂停记录。浏览器分流会打开目标网页。官网不使用分析脚本或追踪 Cookie。

兼容性，说明白。
