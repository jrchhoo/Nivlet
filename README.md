## 当前版本

当前候选：`v1.0.0-rc.5` / Build 13。最终安装版辅助功能已复核开启，TG→Chrome 无闪现已由用户确认。

**v1.0.0-rc.5 · 应用 1.0.0 / Build 13 · 预发布测试版**

目前提供 Apple Silicon（arm64）的 DMG、ZIP 和 SHA-256 校验文件。包声明最低 macOS 13.0；其他 macOS、Intel、多显示器及跨机器安装尚未全面验收。

> 当前安装包使用 ad-hoc 开发签名，尚未完成 Developer ID 签名和 Apple 公证，下载后可能被 macOS 阻止打开。请先了解这一限制，再决定是否试用。它还不是正式稳定版。

Nivlet 是品牌名，Nivlet for Mac 是展示名称；安装的应用仍为 `Nivlet.app`，无需另外安装 Hammerspoon，也无需编辑代码。

## 功能

| 功能 | 可以做什么 |
| --- | --- |
| 剪贴板 | 记录文字与图片，搜索、暂停、图片预览，可选跨重启保留 |
| 窗口管理 | 29 项操作：半屏、四角、三分区、九宫格、居中、缩放、跨屏与恢复 |
| 系统信息 | 菜单栏网速，以及 CPU、内存、磁盘、网络地址和日期的显示控制 |
| 输入法 | 切换应用时自动切换到为它指定的输入法 |
| 应用启动 | 为常用应用绑定快捷键，启动或切换到前台 |
| 浏览器分流 | 按域名或来源应用，选择打开网页的浏览器 |
| 配置迁移 | JSON 导入、导出、默认示例及部分模块导入 |
| 通用设置 | 中英文、深浅色、登录启动、权限检测和标签排序 |

## 安装与开始使用

1. 从 [Releases](https://github.com/jrchhoo/Nivlet/releases/tag/v1.0.0-rc.5) 下载 **DMG 或 ZIP，任选一个**。
2. 将 `Nivlet.app` 放入“应用程序”文件夹并打开，只运行一份应用。
3. 点击菜单栏 **N 图标 → 设置…**，也可以再次打开 App 进入设置；`Command+,` 在 Nivlet 中也可打开设置。
4. 按需启用功能、填写规则，然后点击窗口**右下角“保存设置”**。通用开关也需要保存；切换标签会保留草稿并提示未保存修改。

窗口管理、输入法规则、剪贴板记录、浏览器规则和应用启动默认关闭。启动后显示剪贴板与系统信息入口，不代表已经开始记录剪贴板。

**权限：**窗口调整和 Option 直接粘贴需要在“系统设置 → 隐私与安全性 → 辅助功能”允许 Nivlet。剪贴板记录、系统信息和应用启动不需要这项权限。开发签名更新后可能需要重新授权。

## 使用说明

### 剪贴板

在“设置 → 剪贴板”启用并保存，再复制新内容。点击菜单栏剪贴板图标查看历史：图片在上、文字在下；图片有缩略图及悬停预览，文字前显示 T 方框。设置页历史仍按时间混排。

| 操作 | 方法 |
| --- | --- |
| 复制历史 | 点击菜单中的条目，再到目标应用粘贴 |
| 直接粘贴 | 按住 Option 点击条目，粘贴到打开菜单前的应用；需要辅助功能权限 |
| 搜索 | 菜单“搜索历史…”或设置页历史搜索框；支持文字，不支持图片 OCR |
| 放大图片 | 设置页图片卡片上的“放大预览” |
| 暂停 | 菜单“暂停记录”；恢复后只记录新复制的内容 |
| 清空 | 菜单或设置页“清空历史…”；确认后删除历史和缓存，**同时清空系统当前剪贴板，无法撤销** |

文本默认最多 50 条，可选 10–100 条；保留时间默认 30 分钟，可选 30 分钟、1/2/4/8/12/24 小时或永久。永久仍受数量上限限制。图片最多 10 张，每张约 10 MiB；文件复制不记录，图片粘贴需目标应用支持。

默认退出后不保留历史。“跨重启保留历史”需单独启用，缓存为本地明文。重复内容会移到最新位置，不补录启用前或暂停期间的内容。复制敏感内容前建议暂停；应用排除和过滤不能识别所有敏感信息。

### 窗口管理与应用启动

在对应设置页启用功能并配置组合键，然后保存。支持字母、数字、方向键、Return、`=` 和 `-`，字母统一大写显示；Backspace 或 Delete 清空按键。默认不预设快捷键。

窗口管理提供半屏、四角、居中、三分区、九宫格、宽高每次增减 40 点及相邻屏幕移动。恢复操作回到本次运行首次调整前的位置。全屏窗口不支持，应用最小尺寸可能限制小格布局；没有相邻屏幕时不会循环移动。

应用启动规则会启动应用或切换到前台。重复添加同一应用会提示并定位已有条目；输入法及浏览器来源规则也会检查重复应用。Nivlet 内快捷键冲突会阻止保存，但无法检测全部第三方快捷键占用。

### 浏览器分流

1. 在“设置 → 浏览器”选择默认目标浏览器，添加域名或来源应用规则。
2. 启用并保存，用“检查匹配”和“按规则打开”验证；“模拟来源”可检查应用规则。
3. 要接管其他应用的网页链接，手动将 **macOS 默认网页浏览器设为 Nivlet**；取消接管时改回原浏览器。

匹配顺序为 **域名 → 来源应用 → 默认目标**。域名按列表从上到下匹配，支持子域名选项及 ↑ / ↓ 排序。支持已安装的 Safari、Chrome、Firefox、Edge 和 Brave，仅处理 HTTP/HTTPS。部分应用不提供可识别的来源，此时按域名或默认目标处理。

### 系统信息与输入法

在“系统信息”选择需要显示的网速、CPU、内存、磁盘、IPv4、IPv6、MAC、公历/星期及农历，保存后生效。设置页显示当前状态；隐藏网速后仍保留信息入口。地址和日期可点击复制。macOS 可能隐藏 MAC 地址，此时显示“系统已隐藏”，与辅助功能权限无关。

在“输入法”添加应用并为其选择已启用的系统输入法，启用并保存；下次切到该应用时生效，未配置的应用保持当前输入法。

### 外观、导航与配置

- 语言支持“跟随系统 / 简体中文 / English”，外观支持“跟随系统 / 浅色 / 深色”。默认跟随系统。
- 主图标可显示或隐藏，剪贴板和系统信息入口独立保留。目标排列为“网速 → 剪贴板 → N”，位置也受 macOS 保存的状态影响。
- 顶部标签可拖动排序；“通用”固定最左、“关于”固定最右。排序自动保存，其他可编辑设置统一点击右下角保存。
- “登录 Mac 时自动启动”保存后生效。可选 Command+L 睡眠默认关闭；启用会覆盖浏览器地址栏等应用的同名快捷键。
- 在“通用 → 配置备份与迁移”导出 JSON 或默认示例。导入时先核对替换范围，未包含模块保持不变，失败恢复原配置。历史、缓存、权限、登录项及系统默认浏览器不随配置导出。详见 [配置说明](CONFIGURATION.md)。

## 隐私

无需账号。配置、剪贴板和系统信息在本机处理，不上传服务器；核心桌面工具可离线使用。持久化剪贴板是**本地明文缓存**，请自行保护导出的配置文件。

打开网页、GitHub 或其他外部链接会联网；当前没有启用更新通道。Nivlet 与个人 Hammerspoon 配置和历史隔离，不读取个人 `~/.hammerspoon`。

## 常见问题

**复制后没有历史？** 确认启用并保存、没有暂停，再复制新内容。文件、排除应用及超过限制的内容不会记录；可在设置页刷新历史。

**快捷键或直接粘贴无效？** 检查辅助功能权限、快捷键冲突及目标窗口是否普通窗口。开发签名更新可能要求重新授权。

**应用规则没有打开指定浏览器？** 确认系统默认网页浏览器是 Nivlet，规则已启用并保存；域名规则优先于来源应用规则。

**有截图、官网或自动更新吗？** 暂未提供。截图工具、官网、更新检查和自愿捐赠列入 [开发计划](ROADMAP.md)。
