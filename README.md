# Nivlet

<p align="center">
  <img src="assets/nivlet-icon.png" alt="Nivlet 应用图标" width="160">
</p>

把常用的 macOS 桌面功能放进菜单栏：剪贴板历史、系统信息、窗口调整、自动切换输入法，按规则选择浏览器，以及快捷键启动应用。使用时无需另外安装 Hammerspoon，也无需编辑配置文件。

**当前代码版本为 v1.0.0-rc.2（应用 1.0.0 / Build 2），已通过本机候选验收，尚未正式公开发布。** 本机包使用开发签名，尚未完成 Developer ID、公证和跨机器验收。安装与首版范围见 [首版说明](RELEASE-1.0.0.md)，自行构建见 [构建说明](DEVELOPMENT.md)。

## 开始使用

1. 将 `Nivlet.app` 放入“应用程序”文件夹并打开。只运行一份应用。
2. 点击菜单栏的**设置图标 → 设置…**，通过顶部标签进入对应功能。`Command+,` 也可打开 Nivlet 设置；应用只保留这一套设置界面。
3. 配置完成后点击窗口右下角的“保存设置”。所有可编辑设置（包括通用开关）保存后生效；切换标签保留草稿，底部会提示未保存修改。窗口管理、输入法规则、剪贴板记录、浏览器规则和应用快捷启动默认关闭，按需启用。

应用启动后会显示单色剪贴板图标和上下两行网速，默认网速在剪贴板左侧，位置会由 macOS 保存。剪贴板图标出现不代表已经开始记录，需先启用并保存。

窗口调整和 Option 直接粘贴需要在“系统设置 → 隐私与安全性 → 辅助功能”允许 Nivlet。其余下列功能无需这项权限。开发版更新后如果权限失效，可重新检查这个应用的授权。

## 菜单栏与外观

在“设置 → 通用”勾选或取消“登录 Mac 时自动启动 Nivlet”，点击右下角“保存设置”后更新登录项。该选项属于当前 Mac 的系统设置，不随 JSON 配置导入导出。

辅助功能已授权时，通用页仅显示绿色状态与“重新检测”；未授权时显示红色状态、用途说明和系统设置入口。

在“设置 → 通用 → 语言”可选择“跟随系统 / 简体中文 / English”，默认跟随系统：中文系统显示简体中文，其他系统语言显示英文。保存后立即切换设置、菜单和提示，剪贴板原文与应用名称保持原样。

在“设置 → 通用”可隐藏或显示黑白 N 主图标，默认显示；修改后点击右下角“保存设置”生效。显示时按“网速 → 剪贴板 → N”相邻排列。剪贴板和系统信息入口不受这个开关影响。隐藏主图标后，再次打开 `Nivlet.app` 即可进入设置；剪贴板和系统信息菜单也保留设置入口。

外观可选择“跟随系统／浅色／深色”，默认跟随系统，仅影响 Nivlet。菜单栏和系统菜单沿用 macOS 外观。应用不再显示内嵌 Runtime 的锤子菜单。

可选勾选“启用 ⌘L 让 Mac 进入睡眠”，保存后按 Command+L 睡眠。默认关闭；启用会覆盖浏览器地址栏等应用的同名快捷键，并检查 Nivlet 内的快捷键冲突。

## 剪贴板：找回刚才复制的内容

1. 打开“设置 → 剪贴板”，勾选启用，按需选择记录图片，点击保存。
2. 在其他应用复制文字或图片，再点击菜单栏 📋 查看历史。菜单中图片在上、文本在下，以分隔线区分，各组从新到旧；设置页仍按时间混排。
3. 点击一条历史将其复制，然后到目标应用粘贴。

| 想做什么 | 操作 |
| --- | --- |
| 查找文字 | 📋 → 搜索历史…，输入关键词；设置页右侧也可搜索 |
| 查看图片细节 | 在历史中点击“放大预览”，关闭后返回历史 |
| 直接粘贴 | 按住 Option 点击菜单历史，粘贴到打开菜单前的应用；需辅助功能权限 |
| 暂停记录 | 在剪贴板菜单暂停，恢复后只记录新的复制内容 |
| 清空历史 | 菜单栏剪贴板 → 清空历史…，或设置页“刷新历史”旁的“清空历史…”；确认后删除 Nivlet 历史和缓存，并清空系统当前剪贴板，无法撤销 |
| 调整记录数量和保留时间 | 设置页左侧修改并保存，右侧保留历史视图 |
| 用快捷键打开菜单 | 展开“可选：菜单快捷键”，配置并保存；默认留空 |

只记录启用后的新内容，不补录此前或暂停期间的复制。重复文字或相同编码的图片会移到最新位置。搜索支持文字内容，暂不识别图片里的文字。

默认退出应用后不保留历史。需要跨重启保留时，勾选“跨重启保留历史”并保存。缓存仅存本机，属于明文；关闭整个功能或清空历史会删除相应记录和缓存。复制敏感内容前建议暂停记录，应用排除和隐私过滤不能识别所有敏感内容。

文本数量下拉可选 10–100 条（每 10 条一档，默认 50）；保留时间可选 30 分钟、1/2/4/8/12/24 小时或永久（默认 30 分钟）。永久仍受数量上限限制，跨重启保留需要单独开启；旧自定义值会保留。图片最多 10 张，每张约 10 MiB。文件复制不进入历史。直接粘贴图片需要目标应用支持图片。

## 系统信息：只显示你需要的项目

点击菜单栏网速查看系统信息。进入“设置 → 系统信息”，可分别控制网速、CPU、内存、磁盘、IPv4、IPv6、MAC、公历/星期和农历的显示，保存后立即生效。

隐藏网速后仍保留 ⓘ 入口，方便再次打开设置。点击菜单中的地址或日期可复制。当前展示本机信息，没有公网 IP 或位置查询。

## 窗口管理：配置自己的快捷键

在“设置 → 窗口管理”启用功能，从“布局分组”选择需要的操作，勾选修饰键，在按键框直接按完整组合后保存。支持字母、数字、方向键、Return、`=` 和 `-`；各组设置一起保存，切换分组不会丢失已填写的按键。

| 分组 | 操作 |
| --- | --- |
| 基本布局 | 左、右、上、下半屏，最大化，恢复原位置 |
| 四角与居中 | 四个四分之一窗口，居中（半宽半高） |
| 三分区 | 左、中、右三分之一，左、右三分之二；竖屏自动按上、中、下排列 |
| 九宫格 | 从左上到右下编号 1–9，每格为屏幕面积的九分之一 |
| 大小与屏幕 | 每次宽高增减 40 点；移到左、右相邻屏幕 |

所有快捷键默认留空；清空某项按键并保存可解除该项绑定。恢复原位置只适用于本次运行中已调整的窗口，多次调整仍恢复首次操作前的位置。跨屏移动后可恢复到原屏幕；若原屏幕已断开，恢复到当前屏幕可见范围。全屏窗口不支持，应用自身的最小尺寸可能限制九宫格或缩小操作。没有对应方向的相邻屏幕时会提示，不循环切换。若提示冲突，请换用其他组合；部分第三方应用的快捷键占用无法检测。

## 输入法：不同应用使用不同输入法

在“设置 → 输入法”添加应用，选择该应用使用的输入法，启用后保存。下次切换到该应用时自动生效；未配置的应用保持当前输入法。可选项来自系统中已经启用的输入法。

## 浏览器：按域名或来源应用打开链接

例如，将某个网站交给 Chrome，将某个应用发出的其他链接交给 Safari。

1. 在“设置 → 浏览器”选择未匹配链接使用的默认目标浏览器。
2. 添加域名规则，填写 `example.com` 并选择浏览器；按需勾选“含子域名”。
3. 需要按来源分流时，点击“添加应用…”并为它选择浏览器。
4. 启用并保存，输入链接，通过“检查匹配”和“按规则打开”试用。可选择“模拟来源”检查应用规则。

优先顺序为 **域名规则 → 来源应用规则 → 默认目标**，域名规则按列表从上到下匹配，可用 ↑ / ↓ 调整顺序。支持已安装的 Safari、Chrome、Firefox、Edge 和 Brave，仅处理 HTTP/HTTPS 网页链接。

需要接管其他应用的网页链接时，在 macOS 的默认网页浏览器设置中手动选择 Nivlet；取消时改回原浏览器。Nivlet 不会替你修改系统默认浏览器。已在本机验证跨应用域名规则、来源应用规则及退出后的首个链接。部分应用可能不提供可识别的来源；此时按域名及默认目标处理。

浏览器设置会显示是否已接管系统网页链接。来源应用规则需要 macOS 默认网页浏览器设为 Nivlet；仍设为 Hammerspoon、Safari 等时，其他应用的链接不会经过 Nivlet。域名规则优先于来源应用规则。

## 应用快捷启动：按键打开常用应用

重复添加同一应用时，会提示并定位到已有条目，保留原配置。输入法和浏览器来源应用规则也采用同样处理。设置快捷键时会标出窗口管理、剪贴板菜单和应用启动之间的重复，并说明冲突对象；冲突解决前不会提交该页的保存。

打开“设置 → 应用启动”，点击“添加应用…”选择应用，为它配置修饰键和字母、数字或方向键，再启用并保存。按组合键会启动应用；已经打开时会切到前台。按键框中按 Backspace 或 Delete 可清空绑定，移除规则或关闭功能后保存也会解除绑定。

默认关闭且没有预设快捷键。与窗口管理、剪贴板菜单或系统快捷键冲突时会拒绝保存；原有配置会保留。应用卸载后会提示重新选择。

## 常见问题

**复制后没有历史？** 检查是否启用并保存、是否暂停，再复制一次新内容。被排除的应用、文件复制或超出大小限制的内容不会记录；设置页可点击“刷新历史”。

**窗口快捷键或直接粘贴没有反应？** 检查 Nivlet 的辅助功能权限和快捷键设置，确认目标是普通窗口。当前开发版采用临时 ad-hoc 签名，更新后可能需要重新授权；正式发布前会完善稳定签名。

**能替代我现有的 Hammerspoon 吗？** 当前仅实现上述功能，与个人配置和历史隔离；其他个人模块没有全部迁入。

**有截图工具吗？** 当前没有。截图后在选区原位置编辑、复制和保存属于后续讨论方案，尚未实现。

## 配置备份与迁移

在 **设置 → 通用 → 配置备份与迁移** 中导出已保存的 JSON 配置，或导出完整默认示例。选择 JSON 导入后，先核对将替换的模块，再确认应用；未包含的模块保持不变。配置不包含剪贴板历史、图片缓存或系统权限，失败时恢复原配置。详见 [配置使用说明与示例](CONFIGURATION.md)。

### 调整设置标签顺序

按住顶部标签并向左或向右拖动，即可调整位置；“通用”固定最左、“关于”固定最右，其他功能只在中间移动。顺序自动保存，重启后保留，也会随通用配置导出/导入。排序不会清除其他页面未保存的输入。

### 本地与隐私

Nivlet 无需账号，窗口管理、应用快捷启动、剪贴板记录与系统信息等核心工具可离线使用。配置、剪贴板和系统信息在本机处理，不上传到服务器；剪贴板是否跨重启保留由你控制，持久历史为本地明文缓存。打开网页和 GitHub 项目链接会通过浏览器联网；当前尚未启用更新通道。

通用页、窗口管理和剪贴板页可查看辅助功能状态并重新检测。macOS 27 可能隐藏 MAC 地址，此时显示“系统已隐藏”；这不是辅助功能未授权。
